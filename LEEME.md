# Tenaza – web frontend

Abrí `index.html` con doble clic (o con la extensión Live Server de VS Code).

- `js/config.js`: WhatsApp, teléfono, dirección, horarios y redes. Editá solo esto antes de publicar.
- `js/menu-data.js`: productos y precios del menú.
- `css/styles.css`: colores y tipografías (variables al inicio).
- `img/`: logo, promo y fotos recortadas de las imágenes originales.
